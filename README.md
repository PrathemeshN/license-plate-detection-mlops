\# License Plate Detection MLOps Platform



Production-oriented machine learning application for detecting

license plate regions in vehicle images.



\## Project Objectives



\- License plate object detection

\- Pascal VOC dataset preprocessing

\- Model evaluation and reporting

\- Single-image inference

\- Bulk ZIP inference

\- Confidence-based review flagging

\- CSV result export

\- Automated testing

\- Git-based development workflow

\- CI/CD automation

\- Dockerized deployment

\- Microsoft Azure deployment

\- Application monitoring



\## Technology Stack



\- Python 3.13

\- FastAPI

\- YOLO

\- Pytest

\- Ruff

\- Black

\- MyPy

\- Docker

\- GitHub Actions

\- Microsoft Azure
